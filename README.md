Generate a Multiplication Table

Description

A Python program that generates the multiplication table of a given number up to a specified limit.

Objective

To practice loops, user input, and formatted output in Python.

Requirements

- Python 3
- VS Code

How to Run

1. Open the project in VS Code.
2. Run "multiplication_table.py".
3. Enter a number and the desired limit.

Input

- A number for the multiplication table.
- A limit up to which the table should be generated.

Output

Displays the multiplication table of the given number.

Concepts Used

- "input()"
- "int()"
- "for" loop
- "range()"
- f-strings
